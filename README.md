# DeepStats Mobile PRO

Професионално мобилно PWA приложение за анализ на мачове, стратегии, билдъри и резултати.

## V20 — един дизайн B, три прозореца и реални клубни емблеми (16.11.2026)

- **Само дизайн B · Data Analytics.** Превключвателят за A/B/C е премахнат. Тъмната/светлата тема остава, като по подразбиране е тъмна.
- **Днес, прозорец 1:** Best of the Day като **един дневен билдър** с всичките му селекции, статуса на всеки крак, истинските емблеми или национални флагове, увереност 9/10–10/10 и общ коефициент, изчислен от произведението на коефициентите. Това е моделно предложение, не потвърден залог.
- **Днес, прозорец 2:** разгъваеми мачове от стратегии **A–F**, които се зареждат за днешната дата от Google Sheets и се обединяват без дублиране на една селекция между стратегии.
- **Днес, прозорец 3:** **всички селекции** за текущата дата, без ограничение до първите три мача.
- **Статистика:** историческите KPI/WR/Yield/P&L, крива на печалбата и резултати по A–F от Oracle вече са в секцията „Статистика“, над съществуващия анализатор. Дневният екран няма тежка Oracle статистическа заявка.
- **Емблеми:** `public/crests/` съдържа реални клубни SVG файлове, `manifest.json`, `coverage.json` и `ATTRIBUTION.md`. `scripts/download-crests.py` автоматично извлича и запазва само проверени съвпадения от публично SVG хранилище и TheSportsDB. `.github/workflows/team-crests.yml` автоматизира добавянето на нови файлове. Първото успешно изпълнение потвърди **277 от 450 имена** с локално копие — останалите са записани като неразпознати (вкл. национални отбори, които използват флагове), с последващо сървърно търсене и ясно видим графичен заместител при липса.
- **Навигация:** Днес, Мачове, Статистика, Стратегии, Профил; Билдъри и Архив остават в Профил.
- **Проверки:** `npm run check` и `tests/ui-contract.test.mjs` се изпълняват от `.github/workflows/ci.yml`. GitHub Actions #40 премина успешно; продукционният Android интерфейс и Oracle статистиките не са потвърдени с автентикиран тест.
- **Поддръжка:** всеки следващ AI трябва да актуализира `docs/MASTER_PLAN.md` и `docs/AI_HANDOFF.csv` при промени.


## Инсталация

1. Качете съдържанието на папката в GitHub репозитория.
2. Свържете репозитория с Vercel.
3. Във Vercel добавете `APP_ACCESS_TOKEN`, `GOOGLE_CLIENT_EMAIL`, `GOOGLE_PRIVATE_KEY`, `SPREADSHEET_ID` и необходимите Oracle environment variables (`ORACLE_USER`, `ORACLE_PASSWORD`, `ORACLE_CONNECT_STRING`, `ORACLE_WALLET_PEM`, `ORACLE_WALLET_PASSWORD`) и `ADMIN_ACCESS_TOKEN`. Никога не слагайте тайни в GitHub. Не добавяйте частния ключ в GitHub.
4. Публикувайте. При стара кеширана версия презаредете приложението.

## Данни и правила

- `СЕЛЕКЦИИ`: всички мачове и текущите BEST OF THE DAY.
- `СТРАТЕГИИ_ДАННИ`: стратегии A, B, C, D1, D2, D3, E, F по флаговете в колони N–W. Един залог може да участва в няколко стратегии; сумата им не е уникален глобален резултат.
- `ДАННИ!L:U`: единствен източник за създадени билдъри. Няма фалшиви или локално измислени билдъри.
- `ДАННИ!A:J`: индивидуални залози за обща статистика.
- `СТАТИСТИКА`: общи KPI на началния екран.

Публичният мобилен интерфейс е само за четене. Има отделни административни Oracle import API маршрути, защитени с `ADMIN_ACCESS_TOKEN`; те записват в Oracle, но не са достъпни от мобилния интерфейс. В интерфейса не се споменават технологии или имена на таблици.

## Проверки

`npm install && npm run check`

Проверете във Vercel мачовете по дата, отварянето на стратегия, наличните билдъри и филтрите за статистика.

## v7 — интерфейс и функционалност
- Начало: ново компактно табло с бърз достъп и Best of the Day, без общи показатели за неизиграни селекции.
- Мачове: групиране по дата и мач; разгъване на селекциите; търсене по отбор, лига и пазар; съществуващите филтри остават.
- Билдъри: отделни табове Best of the Day и Моите билдъри; предложенията са обозначени като предложения, а не реални залози.
- Статистика: локално запазване и зареждане на собствени комбинации от категории, без промяна на основните данни.
- PWA: нова версия на статичния кеш. Иконата не е променяна.
- Визуална система: по-изчистени тъмни панели, компактни групирани карти и единен стил.

### Проверка след публикуване
Проверете ръчно с реални данни дати с/без срещи, стратегии с припокриващи се селекции, дати с/без собствени билдъри и избрани статистически комбинации. Този архив не е проверяван чрез реален Vercel deployment.
